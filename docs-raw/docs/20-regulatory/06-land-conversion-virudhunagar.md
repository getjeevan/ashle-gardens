## Step-by-Step Conversion Process

### BEFORE APPLYING — Prerequisite checks
1. **Clear the D2002/6 notation** on Patta 113 fields (149/14A, 149/14B, 149/6)
   - Visit Kariapatti Tahsildar with Patta 113 — ask for the original mutation order from 2002
   - If it's a court partition, get certified copy of court order confirming settlement
   - Must be resolved before conversion application
2. **Verify Patta 113 owner status** — both Silukka Nayakkar AND Vellaisamy Nayakkar (or their legal heirs) must sign the application

### Step 1 — Section 27 Application to Kariapatti Tahsildar
**Office:** Kariapatti Taluk Office, Kariapatti, Virudhunagar Dist
**Form:** Standard Form for Agricultural Land Conversion (varies by district)
**Documents needed:**
- Patta (latest copy from eServices portal, all 3 patta numbers)
- Chitta and Adangal extracts
- FMB (Field Measurement Book) sketch — T.KADAMBANKULAM4S1 and S2 (already in your possession)
- Encumbrance Certificate (EC) for last 30 years — from Sub-Registrar Kariapatti
- Site plan showing proposed use
- NOC from adjacent landowners (Section 27 enquiry)
- ID proof of all patta holders

**Fee:** ₹40–60 per sq metre (for nanjai land — higher than punjai ₹20–40)
**For 4.595 acres (18,596 sqm) at ₹50/sqm = approximately ₹9.3 lakh in conversion fees**

### Step 2 — WRO / PWD NOC (Nanjai-specific extra step)
**Because land is canal-irrigated (Irrigation Code "C"), this is mandatory**
- Apply to Executive Engineer, PWD/WRD (Water Resources Department), Virudhunagar
- Confirm: Is this land under any irrigation command area (ayacut)?
- If under ayacut: need formal delisting from irrigation command — can take 2–4 extra months
- WRO will inspect if conversion would affect irrigation to neighbouring fields

### Step 3 — Section 27 Enquiry
- Tahsildar issues public notice
- Adjacent landowners have 30 days to object
- Inspector visits and submits report
- Common objections: impact on drainage, water flow, existing farming

### Step 4 — DRO/RDO Order
- Virudhunagar Revenue Divisional Officer reviews Tahsildar report
- Issues conversion order (Form as per TN Land Reforms Act)
- Appeal period: 30 days for affected parties

### Step 5 — Patta Mutation
- After conversion order, apply to Tahsildar for patta mutation to "non-agricultural"
- Land classification changes from "Nanjai/Punjai" to "House Site" or "Commercial"

## Top 3 Failure Points (and how to avoid)

### 1. D2002/6 notation not resolved
**Risk:** Application stalled at Tahsildar — they won't process without clarity on the 2002 entry
**Action:** Resolve BEFORE applying — get certified copy of the mutation/court order from 2002

### 2. WRO refuses NOC (land under active irrigation command)
**Risk:** If neighbouring farmers depend on same canal water, WRO may refuse
**Action:** Survey if adjacent farms are active (not fallow). If active, negotiate with neighbours. Consider converting only the portion NOT in canal command area first.

### 3. Link document chain gap
**Risk:** EC reveals a transaction in the 30-year chain that's undocumented
**Action:** Get EC immediately. Identify gaps. Each gap needs a court decree or affidavit.
